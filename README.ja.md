## <img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Flowerly.git
````

### 2️⃣ プロジェクトへ移動

```bash
cd Flowerly
```

### 3️⃣ Unity Hubに追加

- **Unity Hub**を開き、**Add**を選択して、クローンした**Flowerly**フォルダを指定します。

### 4️⃣ プロジェクトを開く

- Unityによるプロジェクトファイルのインポートが完了したら、**Assets**フォルダ内からメインシーンを開きます。

### 5️⃣ プロジェクトを実行

- Unity Editorの**Play**ボタンを押してFlowerlyを起動します。

<img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/howItWorks.gif" width="35"/> 仕組み

1️⃣ **Flowerly**を起動し、AR機能を使用するためにカメラへのアクセスを許可します。

2️⃣ 周囲をスキャンして、床やその他の平面を検出します。

3️⃣ 検出された平面をタップして、花を植えます。

4️⃣ リセットボタンを使用すると、植えたすべての花を削除できます。
