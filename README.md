## <img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/Flowerly.git
```

### 2️⃣ Navigate to the Project

```bash
cd Flowerly
```

### 3️⃣ Add to Unity Hub

- Open **Unity Hub**, select **Add**, and choose the cloned **Flowerly** folder

### 4️⃣ Open the Project

- Once Unity finishes importing the project files, open the main scene from the **Assets** folder

### 5️⃣ Run the Project

- Press the **Play** button in Unity Editor to launch Flowerly

## <img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/howItWorks.gif" width="35"/> How It Works 

1️⃣ Open **Flowerly** and grant camera permissions for AR functionality.

2️⃣ Scan your surroundings to detect surfaces.

3️⃣ Tap on a detected surface to plant a flower.

4️⃣ Use the reset button to clear all flowers.
