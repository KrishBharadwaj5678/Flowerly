## <img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Flowerly.git
````

### 2️⃣ Переход в папку проекта

```bash
cd Flowerly
```

### 3️⃣ Добавление проекта в Unity Hub

- Откройте **Unity Hub**, выберите **Add** и укажите клонированную папку **Flowerly**

### 4️⃣ Открытие проекта

- После завершения импорта файлов Unity откройте основную сцену из папки **Assets**

### 5️⃣ Запуск проекта

- Нажмите кнопку **Play** в Unity Editor, чтобы запустить Flowerly

<img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

1️⃣ Откройте **Flowerly** и предоставьте приложению доступ к камере для работы AR-функций.

2️⃣ Просканируйте окружающее пространство для обнаружения поверхностей.

3️⃣ Нажмите на обнаруженную поверхность, чтобы посадить цветок.

4️⃣ Используйте кнопку сброса, чтобы удалить все цветы.
