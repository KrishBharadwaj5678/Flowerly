## <img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Flowerly.git
````

### 2️⃣ Navegar até o Projeto

```bash
cd Flowerly
```

### 3️⃣ Adicionar ao Unity Hub

- Abra o **Unity Hub**, selecione **Add** e escolha a pasta **Flowerly** clonada.

### 4️⃣ Abrir o Projeto

- Após o Unity terminar de importar os arquivos do projeto, abra a cena principal na pasta **Assets**.

### 5️⃣ Executar o Projeto

- Pressione o botão **Play** no Unity Editor para iniciar o Flowerly.

<img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/Flowerly/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como Funciona

1️⃣ Abra o **Flowerly** e conceda permissão para acessar a câmera, necessária para os recursos de AR.

2️⃣ Escaneie o ambiente ao seu redor para detectar superfícies.

3️⃣ Toque em uma superfície detectada para plantar uma flor.

4️⃣ Use o botão de reinicialização para remover todas as flores.
